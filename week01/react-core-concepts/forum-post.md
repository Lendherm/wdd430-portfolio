## Post text

This week I practiced the three React basics in a small HTML file with React, ReactDOM, and Babel.

**What I built**
- A `Greeting` component that takes a `name` prop and shows a personalized message
- A `Counter` component that uses `useState` so the count updates when I click a button

**In my own words**
- A **component** is a reusable function that returns JSX for one piece of the UI.
- **Props** are read-only values a parent sends to a child to customize it (like different names).
- **State** is data that can change; when you call the state setter, React re-renders so the screen stays in sync.

**Question for the class:** When would you keep data in props vs move it into state inside the child component?
