# Week 01 Forum — Stripe Dashboard

Material listo para la actividad de WDD 430 (full-stack layers).

## Archivos

| Archivo | Para qué sirve |
|---|---|
| `forum-post.md` | **Texto para pegar en Teams** (Week 01 Forum) |
| `architecture-diagram.png` | **Diagrama en PNG** — adjunta esta imagen al post |
| `architecture-diagram.html` | Fuente del diagrama (por si quieres editarlo) |
| `architecture-diagram-ascii.txt` | Misma arquitectura en ASCII (backup / texto) |
| `stripe-tech-stack-research.md` | Investigación completa (frontend, backend, data + fuentes) |

## Cómo entregar (Step 4)

1. Abre el canal **Week 01 Forum** en Microsoft Teams.
2. Copia el texto de `forum-post.md` (sección “Post text”).
3. Adjunta `architecture-diagram.png`.
4. Publica el post.

## Resumen rápido del stack

- **Frontend:** React + TypeScript + Sail + CSS/Sass  
- **Backend:** Ruby (+ Sorbet), Go, REST API/Webhooks, AWS, Docker/K8s  
- **Data:** DocDB (MongoDB), Redis, Elasticsearch, Kafka
