Data flow example: A merchant opens Payments in the Dashboard → React sends an authenticated request to Stripe’s API → Ruby services authorize the user and query DocDB (and maybe Redis/Elasticsearch) → JSON comes back → React re-renders the payments table. External apps can also get webhooks when payment events occur.
